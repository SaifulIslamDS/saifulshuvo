# v0.2.0 — Real Portfolio Content Integration

## Summary

This release replaces generic portfolio copy with real professional positioning, verified contact information, expanded skill groups and detailed project summaries. It also adds a persistent light/dark theme system for desktop and mobile visitors.

## Added

- Icon-only light/dark theme toggle in the responsive header
- Theme preference persistence through `localStorage`
- System-theme detection on first visit
- Pre-hydration theme script to reduce visual flashing
- Light-theme styling for public and admin-preview interfaces
- Real professional positioning and career direction
- 13+ years broader professional experience statement
- 7+ years website-development experience statement
- Real contact email, GitHub, LinkedIn and Dhaka location
- Professional foundation section
- Expanded analytics, AI, development, CMS, business and creative skill groups
- Real portfolio descriptions for:
  - Data Analytics Portfolio
  - PromptKarigor
  - InsightReport
  - HSF ERP
  - AyatFinder
  - QC Bondhu AI
  - EduNexa
  - Nexora ERP
- Verified live/source buttons only where a URL is known
- Improved project-role descriptions
- Expanded metadata and search keywords

## Updated

- Hero headline, role and call-to-action content
- About and career-focus sections
- Services and capability descriptions
- Project page and project-detail copy
- Contact page and footer
- Package version to `0.2.0`
- pnpm version declaration to `11.18.0`
- pnpm build-script approval for `sharp`

## Current limitations

- Admin dashboard is still a UI preview
- Contact form is not connected to a backend
- CV download is not yet available; the current action opens an email request
- Blog posts are planned content placeholders
- Project screenshots and deeper case-study metrics will be added later
