# Roadmap

## v0.4.0 — Project CMS

- Read public projects from Supabase
- Admin project list from database
- Create, edit and preview projects
- Draft, publish and archive workflow
- Featured projects and ordering
- Audit events

## v0.5.0 — Blog CMS

- Database-backed public blog
- Rich text or Markdown editor
- Categories, SEO and scheduled publishing
- Draft preview

## v0.6.0 — Skills and Site Settings

- Manage skill groups and skills
- Edit profile and social links
- Manage homepage copy and SEO settings
- Revalidation after publishing

## v0.7.0 — Media, CV and Contact

- Supabase Storage buckets and RLS
- Profile and project image management
- CV upload and active version
- Contact submission persistence
- Admin inbox and spam controls

## v0.8.0 — Content Migration and Quality

- WordPress content inventory and migration
- Redirect map
- Accessibility and performance audit
- Structured data and social previews

## v1.0.0 — Production Portfolio CMS

- Final content and proof assets
- Custom domain migration
- Search Console and analytics
- Security and release audit
