- Responsive public portfolio with persistent light/dark themes.

- Homepage, Skills, Experience and Services CMS.
- Contact form, private inbox, abuse controls and optional Resend notifications.

- Consent-aware optional GA4/Plausible loading.
- First-party page views, Core Web Vitals and bounded client-error telemetry.
- Analytics dashboard, retention and purge workflow.
- Security headers, no-store admin/API policies, error boundaries and health checks.
- Accessibility and reduced-motion improvements.
- RLS-protected database and append-only CMS audit events.
- Node.js 24 LTS runtime baseline.
